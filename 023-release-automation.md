# 023 – cargo-dist and cargo-release: builds, changelog, archives, checksums

## Goal

Turn "tag a version" into a complete, repeatable release: version bump, changelog, binaries for
all platforms, archives, checksums, installers – automated in CI.

Example: `examples/023-release-automation` (`platctl-rel`) + `dist-workspace.toml` and
`.github/workflows/release.yml` in the workspace root.

## Key concepts

### The release pipeline

```
developer                         CI (GitHub Actions, generated by cargo-dist)
─────────                         ────────────────────────────────────────────
git-cliff  → CHANGELOG.md         on tag push:
cargo release patch --execute       plan → build per target (native runners)
  bump version, commit, tag, push   → archives (.tar.xz / .zip) + .sha256
                                    → installers (sh, ps1), Homebrew formula
                                    → GitHub Release with notes from CHANGELOG
                                    → publish jobs (Homebrew tap, ...)
```

Versioning: Semantic Versioning (MAJOR = breaking, MINOR = features, PATCH = fixes). For CLIs,
breaking = removed/renamed commands or flags, changed output formats, changed exit codes.

### cargo-dist (`dist`)

```toml
# dist-workspace.toml
[dist]
cargo-dist-version = "0.32.0"
ci = "github"
targets = ["aarch64-apple-darwin", "x86_64-apple-darwin", "aarch64-unknown-linux-gnu",
           "x86_64-unknown-linux-gnu", "x86_64-unknown-linux-musl", "x86_64-pc-windows-msvc"]
installers = ["shell", "powershell", "homebrew"]
tap = "example-org/homebrew-tap"
publish-jobs = ["homebrew"]
checksum = "sha256"
```

```toml
# package Cargo.toml – opt in (the workspace has publish = false)
[package.metadata.dist]
dist = true
```

| Command | Does |
|---------|------|
| `dist init` | interactive setup (writes config, `[profile.dist]`, workflow) |
| `dist generate` | regenerate `.github/workflows/release.yml` after config changes |
| `dist plan` | show what a release would produce (CI checks the workflow is up to date) |
| `dist build --artifacts=local` | build this machine's archives + checksums into `target/distrib/` |
| `dist build --artifacts=global` | installers, Homebrew formula, `sha256.sum`, source tarball |

Artifacts (from `dist plan`):

```
ex023-release-automation-aarch64-apple-darwin.tar.xz        [bin] platctl-rel, [misc] CHANGELOG.md, README.md
ex023-release-automation-aarch64-apple-darwin.tar.xz.sha256
ex023-release-automation-x86_64-pc-windows-msvc.zip
ex023-release-automation-installer.sh / .ps1               curl … | sh, irm … | iex
ex023-release-automation.rb                                 Homebrew formula with per-platform URLs + sha256
sha256.sum, source.tar.gz
```

- tags: `v1.2.3` (single package) or `<package>-v1.2.3` (workspace with several releasable packages),
- `[profile.dist]` (inherits release + thin LTO, strip) is used for release binaries,
- the generated workflow uses native runners per target – no cross toolchains needed (step 021 by hand),
- release notes are taken from the matching CHANGELOG section.

### cargo-release

```toml
# release.toml (next to the package)
tag-name = "{{crate_name}}-v{{version}}"
publish = false
allow-branch = ["main"]
pre-release-commit-message = "chore(release): {{crate_name}} {{version}}"
[[pre-release-replacements]]
file = "CHANGELOG.md"
search = "## \\[Unreleased\\]"
replace = "## [Unreleased]\n\n## [{{version}}] - {{date}}"
```

```bash
cargo release patch                 # DRY RUN by default – shows the diff
cargo release minor --execute       # bump, replace, commit, tag, push → triggers the dist workflow
```

Alternatives: `release-plz` (opens release PRs from CI, uses git-cliff internally),
`cargo-smart-release`.

### Changelog: Keep a Changelog + git-cliff

- `CHANGELOG.md` for humans: sections Added/Changed/Fixed/Removed per version, `[Unreleased]` on top,
- **git-cliff** generates it from Conventional Commits (`feat:`, `fix:`, `feat!:` = breaking),
  grouped by a Tera template (`cliff.toml`); `--bumped-version` suggests the next SemVer
  (`feat!` → major),
- non-conventional commits can be filtered out (`filter_unconventional = true`).

```
## [0.4.0] - 2026-10-02
### Added
- add --dry-run
- rename --env to --environment (**breaking**)
### Fixed
- exit code 2 on usage errors
```

### Checksums

`sha256sum -c file.tar.xz.sha256` lets users verify downloads; installers verify automatically.
Checksums prove integrity, not origin – signatures and provenance: step 025.

## Example walkthrough

- `examples/023-release-automation/` – binary, `CHANGELOG.md`, `README.md` (packed into archives),
  `release.toml` (cargo-release), `cliff.toml` (git-cliff), `[package.metadata.dist]`.
- `dist-workspace.toml`, `[profile.dist]` in `Cargo.toml`, `.github/workflows/release.yml` (generated).

## Try it

```bash
cargo install cargo-dist cargo-release git-cliff --locked
dist plan
dist build --artifacts=local --target aarch64-apple-darwin      # your host triple
ls target/distrib && (cd target/distrib && shasum -a 256 -c *.tar.xz.sha256)
dist build --artifacts=global && less target/distrib/*.rb
cargo release patch -p ex023-release-automation --allow-branch '*' --no-push   # dry run
git cliff -c examples/023-release-automation/cliff.toml --unreleased             # needs conventional commits
```
